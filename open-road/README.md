# Open Road

A small open-world driving game. One red sports car, a big map, and an engine sound that revs as you drive.

This project is separate from Cookie Guard.

## Play

```bash
cd open-road
npm install
npm run dev
```

Open the link Vite prints (usually http://localhost:5173). Click **Drive**, then turn your sound on.

## Controls

| Key | What it does |
| --- | --- |
| W or Up | Gas |
| S or Down | Brake, then reverse |
| A D or arrows | Steer |
| Space | Handbrake slide |
| C | Chase, bumper, or hood camera |
| H | Horn |
| R | Back to the start |

The on-screen buttons do the same thing. A controller works too: right trigger gas, left trigger brake, A to slide, Y for the camera, B for the horn.

Stay on the gray road to go fast. Grass, dirt, sand, and the lake are slower. The glowing minimap shows the roads, the lake, and your car.

The engine, wind, tire squeal, horn, and bump sounds are generated in the browser. The car is an original design called Comet, not a real brand.
