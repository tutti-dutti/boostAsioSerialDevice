# Games

## Open Road

Open-world driving. One car, a big map, and a live engine sound. Cookie Guard is unchanged.

```bash
cd open-road
npm install
npm run dev
```

See `open-road/README.md` for how to drive.

## Cookie Guard

Kid-friendly idle tower defense game inspired by the *format* of Summoner's Greed — new story, characters, and setting.

Play it:

```bash
cd game
npm install
npm run dev
```

See `game/README.md` for how to play.
