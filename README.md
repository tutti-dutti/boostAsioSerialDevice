# Cookie Guard

A kid-friendly **top-down idle tower defense** game.

Protect your giant magic cookie with animal friends. No ads.

## Play

```bash
cd game
npm install
npm run dev
```

Then open the link in your browser (usually http://localhost:5173).

## What’s in the game

- Top-down map (Summoner’s Greed style view)
- Summon animal friends and place them on the path
- Basic forest animals, Tier 2, Legendary, and GOD tiers
- Specials: Fox walls, Fish Floppy Fin + evolve to Shark/Megalodon, Red Panda GOD attacks
- Saves in your browser

Full animal list and how-to: see [`game/README.md`](game/README.md).
