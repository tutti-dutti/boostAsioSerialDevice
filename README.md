# Games

## Open Road

Open-world driving. One car, a big map, and a live engine sound. Cookie Guard is unchanged.

Play it online: https://open-road-632221334464.us-central1.run.app

```bash
cd open-road
npm install
npm run dev
```

See `open-road/README.md` for how to drive. Redeploy with `scripts/deploy-open-road-gcp.sh` (see `open-road/DEPLOY.md`).

## Cookie Guard

Kid-friendly idle tower defense game inspired by the *format* of Summoner's Greed — new story, characters, and setting.

Play it:

```bash
cd game
npm install
npm run dev
```

See `game/README.md` for how to play.
